👤 个人资料

📱 联系方式

图标可填：apple、qq、wechat、telegram、github、email/mail、twitter、globe、cloud、image、compass、link。填 QQ/qq 都会显示 QQ 图标。

🗂️ 站点分类

不添加分类时前台保持当前平铺；添加分类并给站点选择分类后，前台显示“我的站点 → 分类 → 站点”。分类和站点都支持排序。

🌐 个人站点

站点图标同样支持：apple、qq、wechat、telegram、github、email、globe、cloud、image、compass、link。

🧊 前台模板

切换后点击底部“保存所有修改”生效；不影响站点数据、壁纸、访问统计和后台登录。

🎨 壁纸

渐变背景是独立类型，可选择深色/浅色；随机动漫是独立类型；随机 API 只使用下面添加的 API；固定图片只使用下面选中的某一张 URL/上传图片。
